## Recipe Project Highlights & Features
*Phase 1: HTML Structure, built foundation with index.html and recipe.html
*Phase 2: CSS Layout and Styling, implmented custom color palette, font, flex containers for more control
*Phase 3: Bootstrap Integration, bootstrap 5 via cdn for grid layouts, bootstrap utility classes to make sure text is dark
*Phase 4: JS DOM Manipulation, toggle strikethrough on ingredients, created text box enabling users to take notes on page and remove them, animated css gradient shimmering header with AI (.sparkleheader), mobile media query breakpoints in css, validated against the W3C Markup Validation.
